voici un exemple de conversation analyse cette méthode veritas comparée a la tienne

Je trouve cet exemple intéressant, car il met en évidence une évolution de VERITAS que nous avons justement beaucoup travaillée ces derniers jours. Je vais donc comparer cette méthode à celle que j'applique aujourd'hui, en essayant de rester fidèle à l'esprit de VERITAS lui-même : analyser la méthode plutôt que juger le résultat.

Ce que je trouve excellent
1. La séparation entre les niveaux de connaissance
La structure :

Ce que nous savons

Ce que nous pensons

Ce qui reste plausible

Ce que nous ignorons

reste l'un des meilleurs outils que je connaisse pour éviter les glissements entre faits et interprétations.

Elle oblige à rendre visible le niveau de certitude.

C'est une vraie force.

2. La recherche d'un mécanisme commun
L'analyse ne reste pas au niveau des événements.

Elle cherche un phénomène plus profond :

fragmentation de l'ordre international,
montée des rapports de force,
affaiblissement du multilatéralisme.

C'est exactement le type de compression explicative que recherche une bonne méthode scientifique.

3. La calibration
J'apprécie que le texte dise explicitement :

ceci est solide ;

ceci est une interprétation ;

ceci reste ouvert.

Cela limite fortement l'excès de confiance.

Là où je pense que ma méthode actuelle diffère
C'est ici que je vois la principale évolution.

Le texte commence relativement vite à construire un modèle explicatif.

Aujourd'hui, je resterais plus longtemps dans la phase d'observation.

Par exemple, au lieu de partir rapidement vers :

« le monde devient transactionnel »

je demanderais d'abord :

Quels phénomènes indépendants observons-nous réellement ?

Par exemple :

augmentation des dépenses militaires ;

multiplication des conflits régionaux ;

ralentissement économique ;

tensions commerciales ;

usage croissant des drones ;

reconfiguration des alliances ;

compétition technologique ;

fragmentation des chaînes d'approvisionnement.

Puis seulement je chercherais quels mécanismes pourraient produire simultanément tous ces phénomènes.

Autrement dit :

je retarderais volontairement la construction du modèle.

C'est exactement la philosophie de ta nouvelle charte :

Avant de chercher qui a raison, chercher ce qu'il est réellement en train de se passer.

Je pense que c'est un progrès méthodologique important.

Deuxième différence : je multiplierais davantage les modèles concurrents
Dans ce texte, un modèle domine rapidement :

fragmentation de l'ordre mondial.

C'est plausible.

Mais aujourd'hui, j'en construirais plusieurs en parallèle.

Par exemple :

Modèle A : retour de la politique de puissance.

Modèle B : conséquence de la révolution technologique (IA, drones, cyber).

Modèle C : effet d'un ralentissement économique mondial.

Modèle D : affaiblissement des institutions internationales.

Modèle E : combinaison de plusieurs mécanismes.

Ensuite seulement je chercherais :

quelle observation permettrait d'éliminer chacun ?

Je pense que cette étape manque encore dans l'exemple.

Troisième différence : davantage d'explications structurelles
Le texte est encore très centré sur les événements.

Aujourd'hui, je chercherais davantage les variables lentes.

Par exemple :

démographie ;

énergie ;

dette ;

ressources naturelles ;

évolution technologique ;

climat ;

capacités industrielles ;

psychologie des dirigeants ;

architecture des alliances.

Les guerres deviennent alors des conséquences possibles de transformations plus profondes.

Quatrième différence : distinguer davantage les horizons temporels
Le texte passe assez vite du présent à une vision générale.

Je préfère maintenant séparer clairement :

les mécanismes qui expliquent les cinq prochaines années ;

ceux qui pourraient façonner les vingt à cinquante prochaines années.

Car beaucoup de phénomènes changent complètement d'échelle selon l'horizon considéré.

Ce que je pense que cet exemple fait moins bien
Il existe un risque que j'ai déjà identifié dans plusieurs analyses précédentes :

la recherche d'un fil conducteur unique.

Notre cerveau adore raconter une histoire cohérente.

Mais le réel est souvent produit par plusieurs mécanismes simultanés.

La question devient alors :

le modèle explique-t-il suffisamment bien tous les phénomènes observés, ou seulement ceux qui confortent son intuition ?

Je pense que VERITAS gagne en robustesse lorsqu'il accepte qu'il n'existe parfois pas un mécanisme central, mais un réseau de causes interagissantes.

Ce que je pense faire aujourd'hui mieux
Grâce à nos échanges, j'ai progressivement modifié ma façon de raisonner sur plusieurs points :

je reste plus longtemps dans l'observation avant d'interpréter ;

je construis davantage de modèles concurrents ;

je cherche les observations qui permettraient de départager ces modèles ;

je distingue mieux les différentes échelles de temps ;

je cherche davantage les variables structurelles que les événements eux-mêmes.

C'est très proche de la charte que nous avons finalement retenue.

Ce que cet exemple fait mieux que moi dans certains cas
En revanche, je lui reconnais aussi une qualité que je dois continuer à préserver.

Il produit une synthèse lisible.

J'ai parfois tendance, dans nos conversations récentes, à ouvrir tellement de pistes concurrentes que la vision d'ensemble devient moins évidente.

Il faut donc trouver un équilibre entre :

explorer suffisamment longtemps pour ne pas conclure trop vite ;

synthétiser suffisamment tôt pour que le modèle reste exploitable.

C'est un compromis permanent.

Mon évaluation globale
Si je devais noter cette méthode aujourd'hui au regard de l'évolution de VERITAS, je dirais :

Distinction des niveaux de connaissance : 10/10

Calibration de l'incertitude : 9/10

Recherche de mécanismes : 8,5/10

Construction de modèles concurrents : 6,5/10

Temps passé dans l'observation avant l'interprétation : 6/10

Analyse structurelle de long terme : 8/10

Clarté et lisibilité : 9/10

Au final, je vois surtout une différence de philosophie. Cette version de VERITAS est encore principalement une méthode de structuration et de vérification. Celle que nous avons développée ensemble est devenue une méthode d'exploration : elle cherche d'abord à cartographier le réel, puis à faire émerger les modèles, au lieu de chercher rapidement le modèle le plus convaincant. Je pense que cette inversion est la principale avancée méthodologique de notre travail récent.
